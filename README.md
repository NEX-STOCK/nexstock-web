## Funcionalidades Principais

| Módulo | Recursos Disponíveis |
| :--- | :--- |
| **Autenticação Segura** | Login e cadastro com validação em tempo real, regras de senha forte, criptografia `SHA-256` e controle de sessão. |
| **Dashboard Dinâmico** | Contadores de produtos cadastrados, total de unidades físicas, alertas de estoque crítico/normal e resumo da sessão. |
| **Controle de Estoque** | Cadastro, edição, exclusão, upload de foto, controle de lote/validade, filtro instantâneo e exportação em **Excel (`.xlsx`)**. |
| **Notas Fiscais** | Registro de entradas e saídas, visualização de comprovantes e **auto-preenchimento OCR simulado** a partir de imagem. |
| **Fornecedores & WhatsApp** | Gestão de contatos e disparo de mensagem pronta de reposição direto no **WhatsApp (`wa.me`)**. |
| **Leitor de Código** | Busca rápida de itens por código de barras / SKU com animação de scanner. |
| **Tema Claro / Escuro** | Alternância instantânea entre *Light Mode* e *Dark Mode* salva no navegador. |
